# XYWY Signal Map

一个新的 Android 基站工具 APK，当前实现了 3 个底部页面：

- 基站地图
- 占用小区
- 我的

## 设计系统（2026-09 重构）

- 主题与令牌集中在 `ui/theme/SignalMapTheme.kt`：品牌蓝 `#0B5CD5` / 频谱青 / 警戒橙三色体系，完整 M3 明暗双主题（含 surfaceContainer 阶梯），统一 Typography 与 Shapes（8/12/16/20/28dp）
- 扩展语义色（成功/警告/信息、毛玻璃、品牌渐变）通过 `MaterialTheme.xywy` 获取
- 共享组件在 `ui/components/XywyComponents.kt`：`XyCard`、`GlassPanelCard`、`SectionHeader`、`PanelHeader`、`StatTile`、`ToggleChip`、`TagChip`、`StatusDot`、`DetailItem`、`InfoBanner`、`EmptyHint`
- 底部导航为悬浮式 Dock（圆角胶囊 + 描边 + 大投影），地图从底部透出
- 地图悬浮面板统一玻璃质感（半透明 + 描边 + 投影），启动图标重绘为天线信号图形
- 动效：地图面板展开/收起（淡入 + 垂直展开）、页面切换 Crossfade 过渡、录制中呼吸灯、RSRP 四格信号条
- 数字场景（指标值/表格/徽标）使用等宽数字（tnum）排版

## 当前能力

- 基于 MapLibre Native Android
- 支持高德普通和高德卫星底图，并可在“我的”中新增/编辑/删除自定义瓦片 URL
- 支持 GPS 定位、首次启动自动定位、GPS/网络定位开关变化自动恢复、右下角回到当前位置
- 支持导入微信工参 Excel（`.xlsx`）、KML 点/线/面、XYWY 测试记录、TIF/ZIP 栅格图层
- 支持工参图层显示/隐藏、样式编辑、导出 CSV/KML、按名称搜索
- 支持按制式、频段筛选扇区
- 扇区按制式/频段显示不同角度、长度、颜色，并考虑方位角
- 支持输入经纬度跳转，例如 `120.8 30.4`、`120.8,30.4`
- 支持双 SIM：
  - 地图双卡叠加
  - 地图双卡分屏
  - 占用小区页按 SIM 分组
  - 每张卡分别显示服务小区与最近邻区
- 支持为 SIM1/SIM2 的 NR/LTE 分别指定工参图层
- 支持当前占用小区拉线、邻区拉线，并按不同 SIM 使用不同颜色
- 主服与邻区只匹配当前位置 5 km 内的工参；超出范围或没有有效定位时不显示工参名称、不画拉线。邻区按同制式、同 PCI 的最近工参显示名称，已有频段、频点信息用于排除冲突，缺失时仍可匹配。
- 大工参启动优化：工参加载优先于栅格缓存修复，匹配索引提前在后台构建并复用；同制式单图层共享索引，频段和图层类型统计不再随信号更新重复遍历全表
- 支持测试记录：地图实时打点，RSRP/SINR 着色，记录可导入、导出、分享
  - 每个采样点追加写盘并同步，正常停止后整理成记录；异常退出后，下次启动自动恢复为“中断恢复”记录
  - 写盘失败时停止采集并提示，已经写入的点保留；日志和索引采用原子替换，兼容原有 `.xywy` 导入导出
- 信号采集每秒读取状态、每 2 秒主动请求小区刷新，同一张卡只保留一个刷新请求；超时后重试
  - 使用手机测量时间戳识别缓存；超过 15 秒未上报新测量时显示“信号过期”，不把旧数值继续记成有效测量
  - 同时处理 LTE / NR 服务小区信号回调，防止旧小区响应覆盖更新的信号，飞行模式切换后清理缓存并重新监听
  - LTE SINR 在 Android 10 及之前按 0.1 dB 换算，Android 11 及之后按 dB 读取；不按数值大小猜单位
- 支持距离/面积测量，以及手动新建点、线、多边形图层

## 网络诊断与记录分析（无需 Root）

- 占用小区页增加采样诊断：服务注册、数据连接、测量来源、测量年龄、过期和未上报指标；实时保留最近 100 条事件。
- 事件明确区分系统状态、采样诊断和参数变化推断。小区 ID 变化不等于确认切换成功，测量消失不等于无覆盖；约每秒观察一次，可能漏掉间隔内的短暂变化。
- 工参诊断区分 ECI/NCI（含 CGI/站号换算）命中、PCI 推测、多候选、禁用匹配和无可用工参。诊断依赖现有索引，不额外扫描全表。
- “我的 → 测试记录 → 回放 / 事件 / 统计”：拖动采样位置、每秒播放一个点、双卡同步查看、点击事件跳转，并可进入地图跟随回放；历史数值在独立回放面板显示，与实时测量区分。
- 按 SIM、订阅和制式分别统计有效 RSRP/SINR、均值、弱覆盖和低 SINR 比例。默认弱覆盖为 RSRP < -110 dBm，低 SINR 为 < 0 dB；过期和缺失不计入指标分母。比例是采样点占比，不是里程或时间占比。
- 采样间隔超过 5 秒或时间倒退时标记不连续，不推测中间发生的网络变化；未记录的时间不能算连续覆盖。
- 新诊断与事件随每个采样点落盘并进入 `.xywy` 导出。旧记录仍可打开，缺少的来源、时间和网络状态显示未知；旧记录事件可根据相邻已有采样推断。

## 构建与验证

```powershell
./gradlew.bat :app:testDebugUnitTest
./gradlew.bat :app:assembleDebug
./gradlew.bat :app:assembleRelease
```

使用 JDK 17 与 Gradle Wrapper 8.10.2。单元测试包含 Robolectric/Compose 界面回归测试；首次运行需要下载 Android 测试运行时。

使用 Android Studio 打开项目根目录，安装 Android SDK 35，并由 IDE 生成本机 `local.properties`（或设置 `ANDROID_HOME`）。仓库不包含 SDK、依赖缓存、签名文件和现场业务数据；导入与地图回归测试仅使用合成样本。

## 已知说明

- 某些 ROM 会限制双卡邻区读取，可能只能拿到主卡或部分邻区
- 某些设备需要定位权限才能读取小区信息
- 主动刷新仍受系统、基带和 ROM 限制；数值长期不变不一定是异常，需结合测量是否过期判断。飞行模式可能重新选择小区、频段或 4G/5G 制式，前后读数不一定来自同一测量对象
- 自定义瓦片 URL 必须包含 `{z}`、`{x}`、`{y}` 占位符
- TIF 栅格支持单色渲染和透明度调整；ZIP 导入可同时携带 `.tfw`、`.prj`
- TIFF 限制为 128 MiB 文件、16,777,216 个源像素且解码像素数据不超过 128 MiB；栅格 ZIP 累计解压不超过 256 MiB，TFW / PRJ 各不超过 64 KiB。坐标需为经纬度，投影坐标应先转换。
- XYWY 导入的 session.json 不超过 64 MiB，压缩包累计解压不超过 128 MiB。两类压缩包最多 1,024 项；这些限制用于降低异常或超大文件造成的内存风险，不能代替低内存手机实测。
- 现有底图代理和用户自定义 HTTP 瓦片需要明文网络支持。面向正式客户时应确认瓦片服务可用性及授权，优先配置 HTTPS 地址。
